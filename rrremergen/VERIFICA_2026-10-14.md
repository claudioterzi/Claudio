## Comportamento della candidata

- Import frontend corretto e proxy Vite verso FastAPI locale `127.0.0.1:8000`.
- Router separato per richiesta; `advanced_options.mode` accetta `local`, `demo`, `cloud` e rifiuta altre opzioni.
- `local` predefinito riusa `.codex/tools/omniroute_local.py`, modello fisso `ollama-local/raffaello-r3:3b`, nessun fallback cloud, massimo 1000 token per risposta.
- Il client locale deve supportare `--stream`: patch opzionale in `tools/omniroute-local-stream.patch`. Il comportamento precedente resta disponibile senza questa opzione. Le credenziali restano nel binding locale esistente.
- `demo` usa un esempio deterministico, etichettato simulazione nella UI e nel manifest. Non prova disponibilità o qualità di un modello.
- `cloud` richiede anche `RRREMERGEN_ALLOW_CLOUD=1` sul server e credenziali del provider. Nessuna chiamata cloud è stata eseguita durante la verifica.
- Errori provider, JSON invalido e controlli PM falliti interrompono la composizione. La UI mostra anche errori SSE e flussi incompleti.
- PM verifica sorgenti, sintassi Python e alcune corrispondenze strutturali. Non prova esecuzione, sintassi JSX, sicurezza o aderenza completa ai requisiti.
- Il risultato è un ZIP con sorgenti e manifest, modalità e chiamate al modello. Integrazioni restano configurazioni; nessuna risorsa esterna viene provisionata.
- Nessun URL live inventato. `/deploy` restituisce 501, senza dichiarare una coda inesistente.
- `/health` distingue configurazione da raggiungibilità non verificata. `models_available`, campo storico, conta modelli configurati.

## Avvio

Dal root, Python 3.10 o successivo:

```powershell
python -m pip install -r rrremergen/requirements.txt
python -m uvicorn rrremergen.api.main:app --host 127.0.0.1 --port 8000
```

In un secondo terminale:

```powershell
cd studio/web
npm ci
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

Aprire `http://127.0.0.1:5173/#rrremergen`. Il gateway e il runner devono essere sul medesimo host del backend. `RRREMERGEN_LOCAL_RUNNER` può indicare il runner canonico installato.
