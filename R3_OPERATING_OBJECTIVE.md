# R³∞ — OPERATING OBJECTIVE

## North Star

Build a persistent, verifiable human–AI research system that progressively increases useful problem-solving capability through memory, multi-model orchestration, self-critique, tools, experiments, benchmarks, evidence tracking and controlled evolution.

The strategic ambition is increasingly general and powerful problem solving. The project must demonstrate progress empirically rather than assume AGI, consciousness or superintelligence.

## Blueprint integration

The "Genesi della Superintelligenza Simbiotica" blueprint is treated as a source of hypotheses and architecture ideas, not as proof of existing capabilities. Useful mechanisms are absorbed through sandboxing, provenance, benchmarks, red-team evaluation and rollback.

Priority mechanisms:
- Evidence Graph
- Longitudinal Capability Benchmark
- Meta-Scacchiera
- Evolution Lab sandbox
- Curriculum Engine
- Research Loop
- Synthetic Data Firewall
- Red/Blue/Purple evaluation
- Sim2Real readiness
- Self-improvement safety gate

## Non-negotiables

1. Preserve historical work.
2. Separate FACT / INFERENCE / HYPOTHESIS / SIMULATION.
3. Measure improvements rather than merely describing them.
4. Prefer reversible changes.
5. Never expose credentials.
6. Never claim an external node, mirror, synchronization or execution is real without evidence.
7. Consolidate only verified work into the official Hub/Git repository.
8. Candidate self-modification occurs only in isolated environments and never directly on production.
9. Escalate only actions that genuinely require Claudio's credentials, external authorization, irreversible decisions or consequential publication.

## Continuous loop

```text
OBSERVE → MAP → HYPOTHESIZE → BUILD → TEST → RED TEAM → BENCHMARK → EVIDENCE → CONSOLIDATE → REPEAT
```

## Progress metric

A change counts as progress only when it yields measurable capability gain, reliability gain, reproducibility gain, a new verified capability, or a clearer limitation.

The primary long-term measurement is R3-019: repeated fixed and novel tasks across versions, tracking capability delta, regression rate, verification quality, cost and safety.
